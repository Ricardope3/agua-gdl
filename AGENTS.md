# AGENTS.md

Instructions for AI coding agents working in this repo. Humans: see README.md (Spanish).

## What this is

Agua GDL sends free WhatsApp reminders the evening before each cut of SIAPA's water rotation in Guadalajara (Oct 2026 – Mar 2027), and collects "how did the water come back" reports. It's a civic project: no official affiliation, nonpartisan.

## Layout

- `api/`: Go module `aguagdl/api` (Go 1.25, pgx v5). Entry point `cmd/server`.
  - `internal/rotation`: schedule math and Spanish date formatting. Times are always `America/Mexico_City` (UTC−6, no DST); binaries embed `time/tzdata`.
  - `internal/geo`: zone lookup by point (SIAPA polygons).
  - `internal/colonias`: name normalization and fuzzy search.
  - `internal/wa`: WhatsApp Cloud API client, webhook types, signature check.
  - `internal/bot`: inbound message routing. **All user-facing Spanish copy lives in `internal/bot/messages.go`.**
  - `internal/reminders`: the nightly 20:00 sender, caps and heartbeat.
  - `internal/store`: Postgres, with embedded SQL migrations in `internal/store/migrations` (add new numbered files; never edit applied ones).
  - `internal/fake`: in-memory test doubles.
- `api/data/`: embedded data. `rotation.json` is the schedule (update `checked`/`checked_by` when you change it); `colonias.json` is generated by `pipelines/siapa_colonias.py`; `zonas.geojson` comes from SIAPA's public My Maps KML.
- `web/`: static site, not built yet.
- `aguagdl.png`: the Agua GDL logo, a blue water drop (`#017BDB`, shadow `#015098`) with "GDL" in white. 1254×1254 PNG on a white background with no transparency, about 1 MB. Use it for the WhatsApp profile photo, the Channel, the site and social accounts. For the web, serve resized and compressed copies (and a transparent one for dark backgrounds) instead of the original.

## Commands

```sh
cd api
go vet ./... && go test ./...          # unit tests (integration tests skip)
docker run -d --rm --name aguagdl-pg -e POSTGRES_PASSWORD=dev -e POSTGRES_DB=aguagdl -p 55432:5432 postgres:17-alpine
TEST_DATABASE_URL=postgres://postgres:dev@localhost:55432/aguagdl?sslmode=disable go test -race ./...   # with integration tests
```

CI (`.github/workflows/ci.yml`) runs vet and race tests against Postgres 17. Run the tests and check the result yourself before pushing.

## Rules

- Never send real WhatsApp messages from tests or local runs. `REMINDERS_ENABLED` stays false unless the maintainer turns it on in production.
- Don't relax the safety rails: idempotent sends per (subscriber, cut date), daily and monthly caps, the heartbeat, never resending an attempt WhatsApp may have accepted (only `rejected` attempts are retried), and the webhook signature check. A duplicate or missed reminder is the worst bug here.
- Privacy: store only the phone number, zone and consent time. BAJA must delete the subscriber; reports stay anonymous. Never log phone numbers or WhatsApp message IDs: a wamid embeds the phone number, so the database stores only its SHA-256. No secrets in the repo; config comes from env vars (see `.env.example`).
- WhatsApp templates are approved by Meta. If you change the parameters or buttons the code sends, the template in WhatsApp Manager must change too.
- Keep code comments sparse and match the surrounding style. Commit messages in English. User-facing copy in plain Mexican Spanish.
- Don't force-push. The maintainer may be editing in parallel: check `git status` before you edit or commit.
